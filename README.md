# SousChef AR

A hands-free cooking assistant for Spectacles (SPECS), built for the Devpost "Learn AR with SPECS" hackathon (Round 2).

SousChef AR guides you through Nasi Goreng Spesial (Indonesian special fried rice) with a world-anchored step card beside the stove: an ingredient checklist with a live counter, seven pinch-navigated steps, per-step timers that keep running across steps with chime + alert banners, and a completion panel with garnish reminders.

## Built with
- Lens Studio 5.25 + CLAD (ls-clad) via the Lens Studio MCP server
- Planned with the plan-lens skill pack — the design brief lives in devpost/design-brief.md
- LEAF acceptance tests in Assets/Tests (nine scenarios covering the brief's five done criteria — all pass)

## Run it
Open SousChefAR.esproj in Lens Studio 5.25+ and run the SPECS preview.
